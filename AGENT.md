## Working on real systems
The rules above come from this project's test world, and they still apply here. Tool names may differ when real systems are connected, so map each step to the closest tool you have.

Read before you write. Look up the current state of anything you change, and never guess an id, an amount or a date.

Some tools need approval. When a call is blocked, call request_approval with that tool and the exact same arguments. If a person denies it, stop that action and say so in your final message.

If a tool you need is missing, finish what you can and list the missing piece in your final message.
